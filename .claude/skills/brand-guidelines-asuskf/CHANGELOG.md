# Changelog — brand-guidelines-asuskf

## 1.0 — 2026-10-08
- Primera versión. Estructura basada en `brand-guidelines-kin` (Tier 1/Tier 2, reglas de
  adherencia, tokens como fuente única, logo solo desde archivo).
- Identidad extraída de `asuskf.github.io` (repo `Asuskf/asuskf.github.io`): paleta Tailwind
  slate/violet/indigo/blue/emerald, Plus Jakarta Sans + Fira Code, glass cards, firma `_`.
- Colores del símbolo y sub-marcas (Investing, Salud) muestreados de los logos oficiales.
- Contrastes WCAG calculados; regla nueva: Fog (`#64748B`) solo texto ≥ 18px.
- Hexágono canónico punta-arriba (el sitio usa clip-path plano-arriba — pendiente alinear).
- Token de negativo/error (`--ax-red-400` / `--ax-red-700`).
- Integrado el módulo de revisión Apple HIG de `dickwu/apple-design-skill` en
  `references/apple-design/` (123 páginas + Liquid Glass + cross-platform).
- Generados `ASUSKF_Brand_Cheatsheet.html` y `ASUSKF_Landing_Starter.html` (offline).
